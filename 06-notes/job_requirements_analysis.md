# 岗位要求分析

## 一、数据分析岗位

### 1. 岗位关键词

SQL、Python、描述统计、参数检验、业务数据监控、用户行为分析、分析汇报、沟通能力。

### 2. 岗位主要工作

数据分析岗位主要负责日常业务数据的监控、整理和分析。工作中需要根据业务需求提取数据，进行统计分析和可视化展示，并把分析结果整理成报告，为业务优化提供参考。

### 3. 需要补充的能力

- SQL 查询能力；
- Python 数据分析能力；
- Pandas 数据处理；
- 描述统计和基础统计检验；
- 数据可视化；
- 业务指标理解能力；
- 分析报告写作能力。

## 二、网络安全数据分析岗位

### 1. 岗位关键词

安全事件、日志分析、网络流量、告警日志、异常行为、攻击识别、威胁简报、安全态势报告。

### 2. 岗位主要工作

网络安全数据分析岗位主要围绕安全日志、流量数据和告警信息进行分析，识别潜在攻击行为和异常访问情况，并协助完成安全事件调查和分析报告。

### 3. 需要补充的能力

- Linux 日志基础；
- HTTP 和网络协议基础；
- Python 日志分析；
- Pandas 数据处理；
- 正则表达式；
- 常见 Web 安全漏洞；
- 安全事件分析报告写作。

## 三、内容产品数据分析岗位

### 1. 岗位关键词

用户增长、产品优化、A/B 测试、用户行为、SQL、Python、Tableau、业务分析模型。

### 2. 岗位主要工作

内容产品数据分析岗位主要负责分析用户在产品中的行为数据，例如阅读、点击、收藏、留存、转化等指标，并结合业务目标提出产品优化建议。

### 3. 需要补充的能力

- SQL；
- Python / Pandas；
- 用户行为分析；
- 留存率分析；
- 转化率分析；
- A/B 测试；
- 数据可视化；
- 产品分析报告。
