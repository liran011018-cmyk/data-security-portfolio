# 数据安全方向学习作品库

## 一、作品库说明

本作品库用于记录本人在数据分析、安全分析、密码学应用和计算机基础方面的学习成果。

本人本科专业为软件工程，研究生阶段研究方向为密码学。希望通过该作品库逐步积累可展示的项目、代码、分析报告和学习笔记，为后续实习和就业做准备。

## 二、作品库内容

本作品库计划包含以下几个部分：

1. Python 工具类项目  
   例如文件处理工具、日志分析工具等。

2. SQL 与数据分析练习  
   例如用户行为分析、电商订单分析、A/B 测试分析等。

3. 安全分析项目  
   例如登录日志异常分析、Web 访问日志分析、安全事件分析报告等。

4. 密码学应用 Demo  
   例如文件哈希校验、文件加密与解密、完整性校验等。

5. 学习笔记  
   包括 Linux、MySQL、HTTP、Web 安全、密码学基础等内容。

## 三、当前学习计划

第一阶段计划用 8 周完成以下内容：

- 搭建作品库基本结构；
- 学习 SQL 和 Pandas 数据分析；
- 完成一个用户行为数据分析项目；
- 完成一个登录日志安全分析项目；
- 完成一个文件加密与完整性校验工具；
- 整理相关学习笔记和项目说明文档。
